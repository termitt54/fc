# Калибровка репутации клубов — 16 октября 2026

Основание: [аудит сезона 29](club-reputation-season29.md). Изменён расчёт
будущих сезонов, без переписывания накопленной репутации и прошлых архивов.
Спортивный Elo не вводился. Формула сборных не менялась.

## Новый расчёт

Нейтральный ориентир престижа соревнования:

`reference = (0,8 × настроенная сила лиги + средняя репутация участников) / 2`.

Средняя вычисляется один раз перед расчётом изменений; обновления клубов
не зависят от порядка обхода. Поправка за итоговое место даёт ориентир
от `reference − 120` до `reference + 120`, ограниченный шкалой 0–1000.
За сезон клуб проходит 2% расстояния до него, не более ±4 пунктов этого
компонента. Раньше использовались 4%, предел ±8 и диапазон от 45% до 100%
заданной силы лиги без учёта репутации участников.

Превышение/недостижение предсезонного прогноза по-прежнему учитывается
отдельно, максимум восемь пунктов с поправкой на силу турнира. Неудачные
сезоны и понижения могут снижать репутацию. Новая модель замедляет её
структурное снижение, но не гарантирует сохранение начальных значений.

Для плей-офф добавлено признание четырёх итоговых мест: базовые бонусы
8 / 4 / 2 / 1, умноженные на `0,5 + 0,5 × сила / 1000`.
Бонус начисляется за итоговое достижение, не за каждый матч длинной серии.

Положительные поправки за результат затухают в последних ста пунктах перед
условным пределом `min(1000, reference + 200)` и равны нулю выше него.
Поэтому бесконечные победы в слабой лиге не создают максимальную репутацию.
Это ограничение касается также положительного сюрприза и побед в чистых кубках.

Отрицательный итог отдельного чемпионского турнира заменяется нулём.
Клубу с уже высокой репутацией титул может сохранить престиж, а не добавить
его. Плохое выступление в другом турнире всё ещё может снизить годовой итог.

Для нескольких соревнований сохраняется общий предел ±20 за год. Одна
структурная поправка берётся из сильнейшего табличного соревнования;
участие в престижном кубке без таблицы больше не подменяет её нулём.
При отсутствии таблиц используется сильнейший кубковый компонент.
Сохраняемый `reputation_delta` теперь равен фактическому изменению после
ограничения шкалой 0–1000.

## Проверки и применение

Регрессии проверяют инерцию, последствия провала, роль соперников,
признание плей-офф, отсутствие отрицательного вклада чемпионства,
годовой предел и 150 последовательных титулов в слабой лиге без достижения
максимального престижа. Сохранены проверки минут и пределов репутации игроков.
Итог: 35 проверок репутации, 24 согласия на предложение, 282 трансферов,
30 продления контрактов — всего 371, без ошибок. На отдельной копии успешно
выполнен реальный переход 29→30: все 128 репутаций совпали с планом,
чемпионские изменения неотрицательны, запись/загрузка сохранила значения.
Сводный машиночитаемый отчёт:
`tests/performance/results/club-reputation-calibration-season29.json`.

Диагностические сцены:

- `tests/performance/club_reputation_audit.tscn`: режим `calibrated` выполняет
  сравнение формул и точный план следующего расчёта, без продвижения сезона.
- `tests/performance/club_reputation_calibration_smoke.tscn`: переход 29→30,
  сравнение всех 128 значений с планом, проверка чемпионов, запись и загрузка
  отдельного слота только в специально подготовленной одноразовой копии.

Обе сцены требуют изолированный user dir `fc-load-benchmark`.
Результаты лежат в `tools/.benchmark-runtime/`, исходная аналитическая копия
и новый пользовательский сейв не перезаписывались.

Для текущей игры нужен перезапуск с новым кодом и обычная загрузка сейва.
Новая формула применяется при следующем подведении итогов сезона.
Исторические значения автоматически не восстанавливаются. Дальнейший
полный многолетний прогон нужен для проверки обратной связи с трансферами
и результатами: повторный расчёт фиксированной истории её не моделирует.
