# Жеребьёвка сборных по Elo — 10 ноября 2026

В международном турнире в разделе «Жеребьёвка групп» доступны:

- Корзины по репутации сборных.
- Корзины по Elo сборных.
- Случайная жеребьёвка без рейтинговых корзин.

Для Elo перед началом каждого розыгрыша берётся актуальный `team.rating.elo`
из состояния сборной. Участники сортируются по убыванию Elo и разбиваются
на корзины размером с число групп. Из каждой полной корзины в каждую группу
попадает одна сборная; распределение внутри корзин случайное. При равном
рейтинге порядок также перемешивается. Дробные значения и Elo выше 1000
учитываются без обрезания; нижняя граница — ноль.

Если Elo ещё не создан, используется существующая начальная формула рейтинга
сборных: `800 + репутация × 1,2`. Новый способ сохраняется как `ELO_POTS`
в `group_draw_rules`; схема базы не меняется. Загрузка сохранения не меняет
уже проведённую жеребьёвку. В сезоны без розыгрыша группы не пересоздаются.

Уточнено поведение старого `REPUTATION_POTS`: раньше оно предпочитало Elo,
если этот показатель присутствовал в данных. Теперь этот вариант использует
именно репутацию и так подписан в редакторе; для Elo есть отдельный выбор.
Пояснение рядом со списком обновляется при переключении способа.

Проверки в изолированном проекте: международная жеребьёвка — 380,
рейтинг сборных — 35, состав дивизионов — 31. Все 446 прошли без ошибок.
Проверены корзины на двадцати случайных последовательностях, различие
репутации и Elo, актуальный рейтинг при устаревшем кэше, редактор,
сохранение и чтение SQLite, начало нового розыгрыша и загрузка сохранения.
