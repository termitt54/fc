# Настройки привлекательности клуба — 10 ноября 2026

Раздел: Настройки → Привлекательность. Переключатель включает соотношение
репутации и Elo либо ограниченную поправку Elo. Неактивные поля отключены,
но их значения сохраняются для следующего переключения.

## Соотношение

Доли репутации и текущего Elo задаются от 0 до 100%, шаг 1 процентный пункт.
Изменение одной доли автоматически дополняет другую до 100%.
Привлекательность = репутация × её доля + текущий Elo × его доля.
Пример: репутация 600, Elo 800, доли 50/50 → 700.
Elo и результат не ограничены сверху значением 1000. Предел поправки и
число матчей в этом режиме не используются.

## Поправка Elo

Сохранено прежнее поведение по умолчанию: предел ±60, полное влияние после
20 отслеженных матчей. Используется спортивная оценка по изменению Elo,
нормированная к шкале репутации, а не непосредственно текущий Elo.
Четверть разницы спортивной оценки и репутации ограничивается пределом,
умножается на min(матчи / период, 1) и прибавляется к репутации.
Результат ограничен диапазоном 0–1000. Доли здесь не используются.

Предел и период редактируются целыми числами от 0 до 1000. Предел 0 отключает
поправку; период 0 включает полное влияние сразу. Период не сбрасывает Elo.

## Применение

Нажатие на число открывает ручной ввод. Enter подтверждает, Escape отменяет.
Изменения применяются только кнопкой «Сохранить». Сброс по умолчанию также
нужно сохранить. Настройки общие для приложения, файл
`user://config/club_attraction.json`; существующие игроки и репутации не меняются.

После сохранения настройки автоматически передаются в C++ при следующем
обращении к расчётам. Для первого подключения обновлённой библиотеки
`fc-native-5-elo-settings` нужен полный перезапуск игры и редактора Godot.
Создавать новый сейв не требуется. Зарплата, роль и качество состава продолжают
проверяться отдельно от привлекательности.
