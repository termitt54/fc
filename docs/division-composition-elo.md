# Состав дивизионов по Elo — 10 ноября 2026

В редакторе турнира, Структура → Состав, доступны три способа:
Случайный, По репутации, По Elo. Значение `ELO` сохраняется в существующей
текстовой колонке `division_sort`; изменение схемы базы не требуется.

По Elo клубы сортируются по текущему `club_elo.elo` от большего к меньшему
и по очереди распределяются между дивизионами. Например, при четырёх
дивизионах первые четыре клуба попадают в разные дивизионы, следующие
четыре распределяются в том же порядке. При равных значениях используется
стабильный порядок ID клуба, как при сортировке по репутации.
Дробная часть Elo и значения выше 1000 сохраняются; нулевой Elo считается
действительным значением. Репутация и привлекательность не подменяют Elo.

Правило подключено к построению первого календаря и к пересозданию сезона.
В новой игре стартовые Elo определяются силой начального чемпионата клуба:
используется общий механизм начальных рейтингов, включая приоритет лиги
над кубком и уровни чемпионатов. При последующих жеребьёвках читается
накопленный Elo. Готовые явно заданные группы сохраняют приоритет над
автоматическим распределением.

Редактор задаёт правила новой игры; выбранный режим хранится в снимке
турнира внутри сейва и используется при смене его сезонов. Загрузка сейва
не перестраивает действующий календарь. Отдельная жеребьёвка сборных
продолжает использовать свои правила корзин.

Проверки в изолированном проекте: 31 проверка распределения, редактора
и сохранения в SQLite; 42 проверки клубного Elo; 262 проверки существующей
международной жеребьёвки; 38 проверок создания новой игры. Всего 373 проверки
прошли без ошибок. Полный многосезонный прогон матчей не выполнялся:
изменение затрагивает состав дивизионов и соответствующий календарь.
