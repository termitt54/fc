# Завершение карьеры после пяти сезонов без клуба

15 октября 2026. Свободный игрок завершает карьеру в межсезонье, если он
провёл **пять сезонов подряд без клуба или больше** и его текущий **CA ниже 70**.
Проверка выполняется после развития и старения за закончившийся сезон.
Игрок с CA ровно 70 защищён от этого правила, как и игрок с CA выше 70.
Обычное завершение карьеры по возрасту продолжает действовать для всех.

Использован существующий `free_agent_seasons`: он увеличивается один раз
при годовом обновлении свободных агентов, перед проверкой завершения карьеры.
После четвёртого законченного сезона игрок ещё остаётся на рынке;
после пятого при CA <70 — уходит в архив. Подписание контракта уже сбрасывает
этот счётчик в TransferMarket; последующее освобождение начинает новый срок.
У находящегося в клубе игрока старое значение счётчика не вызывает уход.

Период без клуба у CA 70+ не обнуляется: если впоследствии CA станет ниже 70,
при следующей годовой проверке учитывается весь непрерывный срок без клуба.

Существующие сейвы сохраняют накопленный срок. Уже просрочившие пять сезонов
игроки с CA <70 уйдут при следующем переходе сезона. Если у старой записи
нет счётчика, отсчёт начинается с наблюдаемого сезона; неизвестные годы
не выдумываются. Загрузка посреди сезона сама игроков не удаляет.
Обновление не меняет исходный пользовательский сейв до обычного игрового
перехода/сохранения; для применения к запущенной игре нужен перезапуск.

Используется общий механизм завершения карьеры: удаление из активного пула,
снимок полного профиля и статистики в истории, сохранение доступа к карточке
из трансферов и архивов. Архивный игрок не возвращается на рынок.

Дополнение: завершивший карьеру игрок без игровой статистики клуба/сборной,
наград и ссылок из журнала трансферов удаляется без записи в архив.
Пустые сезонные строки и история развития сами по себе не являются основанием
для сохранения. Даже частичная старая статистика (например, минуты без числа
матчей) сохраняется. Ссылки из трансферов защищены от пропажи профиля.
Удалённый профиль также убирается из временного буфера завершивших карьеру;
счётчик ID не откатывается. Более ранние ветки сейвов и уже записанный архив
не очищаются. Условия самого завершения карьеры, включая защиту CA 70+, прежние.
SaveHistory с проверкой удаления, архива и старой ветки: 146 проверок без провалов.

Проверки: 130 в SaveHistory и 68 в PlayerDevelopment, без провалов.
Проверены границы 4/5 сезонов и CA 69/70/71/90, игрок с превышенным сроком
из старого сейва, отсутствие счётчика, сброс при подписании, новый срок после
освобождения, возрастное завершение карьеры у CA 90, профиль и статистика
после ухода, сохранение/загрузка и возврат к старой ветке сейва.
SQL-ошибки в SaveHistory намеренно вызываются прежними проверками отката.

Это уменьшает число игроков для ежедневной обработки, но само по себе
не ускоряет подбор составов. Первая массовая архивация может временно
увеличить время одного перехода сезона.

Проверка окончательного правила с исключением CA 70+ на копии автосейва
сезона 29: после перехода активных игроков 9268 вместо 15 823 в прежнем
контрольном прогоне (на 6555 меньше). Общее число завершивших карьеру при
переходе — 7381, включая обычный возрастной уход. Эти числа нельзя выдавать
за количество ушедших только по новому правилу.

На одинаковом отрезке дней 2–8 медиана синхронного дня из 64 матчей уменьшилась
с 655 до 582 мс, около 11%. Восстановление — со 178 до 104 мс, около 41%.
Рынок последнего дня — с 1,82 до 0,91 с. Переход сезона с первой массовой
записью архивов занял 26,50 с против прежних 25,11 с. Это headless-замеры
одного отрезка на текущем компьютере, не оценка времени реальной отрисовки.
Состав свободных агентов намеренно изменился, поэтому результаты матчей
с прежней версией не обязаны совпадать. Исходный пользовательский сейв
не прокручивался и не перезаписывался. Локальный результат:
`tools/.benchmark-runtime/user-day-performance-snapshot/day-performance-retirement-ca70.json`.
